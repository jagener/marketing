- 1~6번은 워드프레스·티스토리 A/B와 **이름까지 똑같이** 씁니다(같은 주제가 여러 출처에서 반복되도록).
- 7번은 지방흡입 계열 글이 74건이라 공통 6개 어디에도 넣기 어려워 따로 둡니다. 티스토리 B의 "체형관리"와 짝을 이룹니다.
- 8번은 기존 "공간 이야기"와 "기타"를 합친 것입니다. 마운자로·디톡스 글은 SVF 지방이식이라는 핵심 주제와 맞지 않으니 신규 발행은 줄이는 것을 권합니다.

### 분류 규칙 (글 하나가 여러 곳에 걸릴 때)
1. 논문·임상·연구 해설 → **연구 리뷰**
2. 지방흡입·지방분해·힙업 → **체형·바디라인**
3. 회복·부작용·사전/사후관리·경과 → **수술 전후 과정**
4. 병원 선택·비용·상담 질문·장비/시설 → **병원·상담 선택 기준**
5. 나머지는 시술 부위로 → 가슴 / 안면 / 리프팅

발행 템플릿의 "카테고리: 공통 체계 매핑표로 자동 지정"(지시서 발행 자동화 P1)에도 이 순서를 그대로 쓰면 됩니다.

## 4. 작업 순서 (네이버 블로그 관리)

1. **카테고리 만들기:** 블로그 홈 → 프로필 아래 **관리** → 상단 **메뉴·글·동영상 관리** → 왼쪽 **블로그**(카테고리 설정)에서 새 카테고리 8개를 만들고 위 순서대로 배치한 뒤 **확인**을 눌러 저장합니다.
2. **글 옮기기:** 내 블로그에서 카테고리(예: SC301의원 게시판)를 연다 → 글 목록 **목록열기** → 오른쪽 **글관리**(체크박스가 나타남) → 「글별 이동표」를 보고 글을 체크 → **카테고리 변경(이동)**으로 새 카테고리를 고릅니다. 목록을 한 페이지에 30개씩 보게 바꾸면 빠릅니다.
3. 기존 4개 카테고리가 0건이 되면 삭제합니다.
4. 카테고리를 옮겨도 글 URL(`blog.naver.com/sc301guide/글번호`)은 바뀌지 않으므로 리다이렉트는 필요 없습니다.

## 5. 함께 처리할 항목 (이동표에 표시해 둠)

- **비미용 적응증 글 21건** (콩팥병·당뇨발·누공·턱관절·발기부전·무릎·심장·신경·전신경화증 등): "연구 리뷰"로 옮기면서 본문 위에 고지 문구를 넣습니다.
  > 해외 연구 동향 소개이며 SC301의원의 진료 항목이 아닙니다.
- **제목 점검 표현 63건**: 후기(22), 완벽, 잘하는, 해답, 혁명, 끝판왕, 최고, 최초, 흉터 없이, 부작용 걱정 없는, 95%, 2배 등. 제목은 자동으로 골라낸 결과입니다. 비판하려고 인용한 표현(예: "보장합니다라는 병원, 조심해야")도 함께 잡혔을 수 있으니, 고치기 전에 문맥을 확인해 주세요. 특히 "후기" 글은 의료법상 치료경험담 광고에 해당할 수 있어 우선 검토를 권합니다.

> 분류는 글 제목을 기준으로 규칙을 정해 나눈 뒤 사람이 한 번 검수한 결과입니다. 본문을 열어 보면 판단이 달라지는 글이 있을 수 있습니다. 이 문서는 법률 자문이 아니므로, 바꿀 문구는 내부 컴플라이언스 검토를 거쳐 반영해 주세요.
